# Security Policy

## Supported Versions

This project is currently in its early stages. Only the latest version is supported with security updates.

| Version | Supported |
| ------- | --------- |
| latest  | ✅ Yes    |
| < latest| ❌ No     |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately by:

1. Going to the **"Security"** tab of this repository.
2. Clicking on **"Report a vulnerability"**.
3. Providing a clear description of the issue and steps to reproduce it.

You can expect an initial response within **48 hours**. I will review the report and let you know if it's accepted or declined, along with an estimated timeline for a fix.

Thank you for helping keep this project safe! 🙏
